# Operator guide — COG

Portal: public procurement (ARMP, `armp.cg`; tender notices via the
BOAMP bulletin, not yet a live self-service e-tendering portal).
Entity registration: RCCM via ACPCE (`acpce.cg`), the national guichet
unique. Tax: NIU via DGID (`impots.gouv.cg/portail-client-web`).
Engagements with a declared prior ARMP exclusion also clear the Décret
n° 2009-156 Art. 146 five-year exclusion-duration cap gate before a
filing can proceed. Hydrocarbons-sector engagements ONLY also clear an
SNPC joint-venture + Congolese-staffing (80%/90%) check (15 November
2019 executive order) -- never applied outside hydrocarbons. Human-gated
filing only: `:filing/draft`/`:filing/submit` always require an explicit
human approval before anything commits, at every rollout phase.
